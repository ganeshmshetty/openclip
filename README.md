# Settings redesign screenshots

Image host for the four settings-redesign draft PRs. This branch carries **no code** — it exists
so the PR bodies can link full-size PNGs without putting them in any PR's diff.

- `shots/before/` — the current `main` behaviour, shared by all four PRs
- `shots/flatten/` — `design/settings-flatten`
- `shots/drilldown/` — `design/settings-drilldown`
- `shots/inspector/` — `design/settings-inspector`
- `shots/router/` — `design/settings-router`

Delete this branch once the PRs are closed.
